# paper-cartoon-reel

**An agent skill that turns a marketing goal into a narrated paper-cartoon Reel.** Give your coding agent a topic, an audience and one action you want viewers to take; it researches hooks, designs a new character and palette, writes the script, builds the animation, voices and sounds it, and renders a 9:16 MP4 for Instagram Reels, TikTok or Shorts.

Built by [The White Whale Agency](https://github.com/The-White-Whale-Agency). Works as a [Claude Code](https://claude.com/claude-code) skill (a plain folder with a `SKILL.md`, so other agents that read skills can use it too).

## Why

Most explainer Reels lose people in the first two seconds, and most "AI video" tools give you clips you can neither edit nor sync to a voice. This skill takes the opposite route:

- **Marketing first.** The goal is views, shares, saves and one action, not animation for its own sake. The hook is generated with whatever marketing and hook skills your agent has, scored, and approved by you before anything is built.
- **A new look every time.** A new character and a new palette are designed for each video. Nothing is inherited from the last one, so a feed of your reels does not look like a template.
- **Exact sync.** The voice is generated per sentence with word timestamps; animations, captions and sound hits are keyed to those words. Nothing is hand-timed.
- **Deterministic and cheap.** The reel is an HTML + GSAP composition checked and rendered locally with [HyperFrames](https://hyperframes.heygen.com): no per-video credits, a repeatable result, and a built-in quality gate (`lint`, `check`, `snapshot`).
- **An orchestrator, not a silo.** It tells the agent to use any other installed skills, plugins and MCP tools, as many as help and in any order (marketing, copywriting, design, research, audio, review), and to record what each contributed.

## How it works

| Phase | What happens |
|---|---|
| 0 Goal | Business goal, the single action, audience pain in their words, platform, language, length (`PLAN.md`) |
| 1 Tool sweep | The agent lists installed skills/plugins/MCP tools and picks every useful one |
| 2 Research and hook | 10+ hook candidates generated by hook/marketing skills, scored; primary + alternate (variant B). Introductions and greetings are rejected as hooks |
| 3 Story, character, palette | 6–9 scenes, one idea each; a new character and palette; script and storyboard. **You approve here** |
| 4 Build | HyperFrames project from the template; scenes written against the word timings |
| 5 Voice and sound | Any TTS that yields `vo.wav` + word timings (Edge TTS bundled); sound effects and mix at -14 LUFS, optionally chosen and verified with [earshot](https://github.com/Leonxlnx/earshot) |
| 6 QA gate | `lint`, `check --json`, snapshots, a marketing checklist, an audio timeline check, optional virality/review tools, a Studio preview for you |
| 7 Render and deliver | `hyperframes render`; MP4, cover frame, caption + hashtags, pinned comment, alternate hook |

## Install

Copy the skill folder where your agent looks for skills.

```bash
git clone https://github.com/The-White-Whale-Agency/paper-cartoon-reel.git
cp -R paper-cartoon-reel/paper-cartoon-reel ~/.claude/skills/      # all projects
# or: <project>/.claude/skills/ for a single project
```

Restart the agent. Then ask for a reel, for example:

> Make an Instagram Reel for a dental clinic: audience is adults who postpone check-ups, the action is "comment BOOK". Use a paper-cartoon explainer.

### Requirements

- Node 22+ (the skill runs `npx hyperframes`) and `ffmpeg`
- Python 3 with `numpy`; `python3 -m pip install --target <project>/.pydeps edge-tts` if you use the bundled voice script
- Optional: the [earshot](https://github.com/Leonxlnx/earshot) MCP server for hearing and verifying sound; other skills and MCP tools make the research and hook phases stronger

## Design decisions worth knowing

- **HyperFrames is the only renderer.** Other video tools (AI generators, editors, motion tools) may supply assets but do not assemble or render the reel, because word-synced captions, stamps and sound need a deterministic, seekable timeline.
- **No default character and no default palette.** The template ships a placeholder character and a placeholder `:root` block, both marked "rewrite for every video". The example project's character is explicitly not to be reused.
- **The voice is the agent's choice.** The build only needs `vo.wav` and `vo_timing.json`; the contract is in `references/tooling-and-voice.md`.
- **One human gate.** The agent shows hooks, character, palette, script and storyboard and waits; everything after is cheap to redo.

## Status

Verified end to end on the bundled example project (voice with word timestamps → synthesized sound mix at -14 LUFS → `hyperframes lint` and `check` → snapshots with two different palettes → a draft MP4 render of 35.7 s at 1080×1920 with audio). The workflow text, the hook and tool-sweep phases and the earshot integration have **not** yet been pressure-tested with fresh agents on a real client brief; expect to tune the wording.
